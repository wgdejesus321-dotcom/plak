# Referências visuais da biblioteca de modelos

A biblioteca do PLAK usa referências de linguagem visual encontradas em pesquisas públicas de bio sites e cartões digitais. Os layouts e configurações dos modelos foram recriados de forma original usando apenas recursos disponíveis no PLAK.

## Referências consultadas

- Pesquisa visual de cartões digitais customizáveis: https://files.manuscdn.com/search-media/310519663988130164/6fj1gLJ4zxf5y8ZQ971oE8/yaeWpsDoxbmVUCYm7G7xY3.webp
- Pesquisa visual do template Bajor Link in Bio: https://files.manuscdn.com/search-media/310519663988130164/6fj1gLJ4zxf5y8ZQ971oE8/whvgCEGmHuaZUHxfvqFnqf.png
- Galeria de exemplos de link in bio para criadores e marcas: https://www.mobilocard.com/blog/link-in-bio-examples
- Referência visual de creator hub: https://files.manuscdn.com/search-media/310519663988130164/6fj1gLJ4zxf5y8ZQ971oE8/FioRvHs5MZnLGjWtJsMQPT.png

As imagens locais em `client/public/template-references/` são usadas como textura/referência visual discreta nos cartões da biblioteca. Elas não são usadas como páginas finais dos clientes; a entrega final é renderizada pelo sistema de temas e campos do PLAK.
