# Visão do editor PLAK Pro Max

O objetivo é que o usuário pense na página como uma composição visual, não como um formulário.

Fluxo recomendado:
1. Escolher um estilo ou estrutura rápida.
2. Trabalhar no canvas.
3. Clicar no elemento que deseja alterar.
4. Arrastar imagens/textos quando necessário.
5. Usar o painel lateral apenas para ajustes precisos.
6. Adicionar blocos conforme a necessidade.
7. Reordenar ou ocultar blocos.
8. Visualizar e publicar.

A biblioteca de blocos foi criada para permitir que uma página de restaurante, loja, profissional, criador ou serviço seja montada com a mesma base, mas com composições completamente diferentes.
